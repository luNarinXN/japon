# Kotoba — личный тренажёр японского

## Запуск на GitHub Pages
1. Распакуй архив. Создай публичный репозиторий на GitHub.
2. Загрузи index.html, style.css, app.js и words.js прямо в корень репозитория, не архивом и не вложенной папкой.
3. В Settings → Pages выбери Deploy from a branch, ветку main и / (root), затем Save.
4. Дождись завершения публикации. Ссылку на сайт GitHub покажет в разделе Pages. Открой её на компьютере и телефоне.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Обновление словаря через ChatGPT
Пришли текущий words.js и новые слова. Попроси дописать их, сохранив старые записи и их id. Замени только words.js в репозитории и сохрани изменение. После публикации обнови страницу на телефоне. Если отображаются старые слова, перезагрузи страницу без кеша или закрой и снова открой сайт.

## Самостоятельное добавление
Открой «Мой словарь» → «Добавить слово вручную». Заполни написание, чтение латиницей, перевод и тему. Изменения сохраняются как локальный черновик. Нажми «Скачать words.js» и замени этим файлом words.js в репозитории. После публикации слова будут доступны на других устройствах. Если файл с таким именем уже скачивали, браузер может назвать новый words (1).js: переименуй его обратно в words.js перед загрузкой.

## Практика
Выбери тему, направление и 4 или 6 ответов. Раунд содержит 10 вопросов. Если слов меньше, вопросы повторяются; если уникальных ответов меньше выбранного числа, вариантов будет меньше. Все варианты берутся только из выбранной темы. Вопросы с одинаковыми написаниями или чтениями не получают неоднозначные альтернативы. Кнопка «Повторить ошибки» тренирует ошибки выбранной темы. Статистика и список ошибок сохраняются только в текущем браузере. Настройки направления применяются при начале нового раунда.

## Что уже в словаре
Пять гласных хираганы и шесть отдельных примеров слов. Это стартовый набор, не утверждение, что все эти слова уже выучены. Для первых занятий выбери тему «Хирагана · гласные». Хирагана — слоговая азбука; её знаки не являются иероглифами. Чтение в этом наборе — латиницей. Обрати внимание: hebi — змея, ebi — креветка, hoshi — звезда.

## Что сохраняется
- Общий словарь: в words.js в GitHub, одинаковый на всех устройствах после обновления страницы.
- Прогресс и черновик: в localStorage отдельного браузера. Очистка данных браузера удаляет их. Автоматического переноса прогресса между телефоном и компьютером нет.
- Сайт и словарь в публичном репозитории доступны другим людям по ссылке.

Никаких ключей, серверов, платных библиотек или сборки. Можно открыть index.html из распакованной папки на компьютере без интернета. Работа сайта GitHub Pages без интернета не гарантируется: офлайн-кеширование не реализовано.

## Проверка
Проверены синтаксис JavaScript и целостность стартового словаря. Визуальная проверка в браузере в среде создания недоступна; после загрузки проверь первый раунд на телефоне и компьютере.
