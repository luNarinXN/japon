# JAPON — MEXT Natural Sciences A Educational Platform (Techno-Glassmorphism Edition)

A static educational platform for MEXT Scholarship (Natural Sciences A) preparation, styled with a Techno-Glassmorphism dark UI.

## GitHub Pages Deployment
1. Extract all files from the ZIP archive directly into your repository root (no subfolders).
2. Commit and push (`index.html`, `styles.css`, `data.js`, `app.js`, `.nojekyll`, `README.md`, `PROJECT_STATUS.md`).
3. Enable GitHub Pages under **Settings → Pages → Branch: main / (root)**.
