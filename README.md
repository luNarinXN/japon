# JAPON — MEXT Natural Sciences A Educational Platform

A complete static educational web platform for MEXT Scholarship (Natural Sciences A) preparation.

## GitHub Pages Deployment
1. Extract this ZIP archive directly into your repository root (all files are in the root without subfolders).
2. Commit and push all files (`index.html`, `styles.css`, `data.js`, `app.js`, `.nojekyll`, `README.md`, `PROJECT_STATUS.md`) to GitHub.
3. Open repository **Settings** -> **Pages**.
4. Select branch `main` (root `/`) and click **Save**.
5. Your site will be live at `https://<username>.github.io/<repo-name>/`.
