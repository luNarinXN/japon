# PROJECT STATUS — JAPON (MEXT Natural Sciences A Platform)

## Overview
JAPON is a static educational platform for MEXT Undergraduate Scholarship (Natural Sciences A) preparation, built with HTML5, CSS3, vanilla JavaScript, and localStorage. Fully compatible with GitHub Pages.

## Features Implemented
- Bilingual educational explanations (English + Ukrainian in parentheses).
- Modules: Dashboard, English & Academic Terminology, Mathematics, Chemistry, Physics, Japanese (Vocab, Kanji, Flashcards), Exam Center, Settings.
- Cumulative Exam System (strictly tests completed topics).
- LocalStorage progress tracking with JSON backup/restore.
